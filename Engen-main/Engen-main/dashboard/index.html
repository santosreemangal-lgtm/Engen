Wallet addresses are saved by the dashboard backend. Monitoring starts only when you press Start Monitoring. Starting it sends public wallet addresses to the public Solana RPC endpoint https://api.mainnet-beta.solana.com. The endpoint may be rate-limited. The first scan establishes a baseline; later scans look for new transaction signatures. Token balance changes are shown when transaction metadata provides them. A balance change alone does not establish whether a wallet bought or sold. This is not a complete token buy/sell tracker. Never enter a seed phrase or private key. No signing or live trading is performed by this interface.
